# A2 — `--mapq-local`: the best local affine competitor score (HG002 test B)

**Date:** 2026-11-21. **Step:** research guideline Pillar A, A2 (count clipped
local competitors inside CERTA). **Code:** `include/certa/core.h`
(`other_candidates`, `Params::mapq_local`, `finish_certified`), `src/cli.h`
(boolean-flag whitelist), `src/map_config.cpp` (`--mapq-local`),
`tests/test_certa.cpp` (differential test). Raw table: [`a2_report.md`](a2_report.md).
Build/eval runners: [`../../build_a2.sh`](../../build_a2.sh),

## Change

`other_candidates` (the MAPQ-only second-best estimate beyond the certified
radius, called for unique-certified reads with no second locus within R)
gains a `local` mode: `*sub` becomes the **best local (clipped) affine score**
among the `S2_TOP` evaluated competitor clusters — BWA-MEM's `XS`, which counts
partial paralogs — instead of the affine score of the closest *end-to-end*
cluster. The returned distance `d2x` and **every certificate field are
unchanged**; with the flag off the code path is byte-identical to before.
`sub_score` feeds the default point MAPQ (`mapq_se_raw`, `sam_output.cpp:328`)
and the `XS:i:` tag (the pair model's margin input).

## Results (31,931,012 mates with a truth; default-mode CPU, same build)

| run | in SAM % | at truth % | misplaced | MAPQ≥20 | ≥40 | ≥60 |
|---|---|---|---|---|---|---|
| baseline | 99.947 | 99.861 | 27,210 | 9,590 | 4,923 | 3,345 |
| `--mapq-local` | 99.947 | 99.861 | 27,210 | 9,562 | **4,891** | 3,325 |

Confident (MAPQ≥40) mates: 31,751,509 → 31,751,306 (−203 demoted, of which 32
were misplaced). Strata (misplaced at MAPQ≥20): segdup 6,662 → **6,639** (−23),
lowmap_segdup 7,696 → 7,672 (−24), difficult 8,777 → 8,753 (−24), easy unchanged.

**Calibration (the key observation):** the MAPQ 50–60 band holds **3,979
misplaced vs 31.9 expected** from `Σ 10^(−MAPQ/10)` — ~125× overconfident,
essentially unchanged by `--mapq-local` (3,999 → 3,979).

## Interpretation

- The change does what it should: it counts clipped partial paralogs as
  competitors and demotes reads whose best local competitor is strong — the
  effect is concentrated in segdup/lowmap, and the certificate is provably and
  empirically unchanged.
- **But the standalone gain is small (−32 confident errors, −0.65%) because the
  default point MAPQ saturates.** `mapq_se_raw ≈ 6.02·(score−sub)·t²` only drops
  below 40 when `score−sub ≲ 16`; a paralog matching half the read clipped
  (`sub ≈ score/2`) still scores MAPQ 60. So a better `sub` cannot, by itself,
  demote the missing-copy reads that dominate the residual. This is exactly
  **Limit 2 (MAPQ posterior saturation)** in the theoretical-limits doc, and the
  calibration table shows it persists (3,979 vs 31.9).
- A1's 14× reduction came from a *fitted* gap→error map applied to **all** mates
  (bypassing `mapq_se`), not from feeding `sub` into `mapq_se`. A2 supplies the
  better competitor signal; realizing the gain needs the **fitted posterior**
  (A3b phantom-copy term, A4 locus prior) and a **pair-model re-fit** on the new
  `XS`, not the saturated point formula.

## Go / no-go

- **A2 is a correct, certificate-safe building block** (default byte-identical;
  flag-gated). Keep it.
- **Proceed to A3b/A4** (phantom-copy posterior + locus prior) and re-fit the
  pair model on the new `XS`/gap features — that is where the A1-validated
  headroom is realized. The relative-horizon competitor search (best + 10–12
  edits, wider bands) is the remaining A2 variant and would extend the signal to
  more divergent competitors; deferred (needs bands beyond `BAND_E2E`).
