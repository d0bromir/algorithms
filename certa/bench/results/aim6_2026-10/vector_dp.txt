# The vectorized band DP row (certa/longread.h band_row; THEORY.md "The band DP row"), 2026-10-15.
# W cells at a time with GCC vector extensions: W = 4 on galaxy (aarch64, Neoverse-N1, NEON, GCC 15.2),
# W = 8 on a2 (x86, Xeon Gold 5218, AVX2/AVX-512 with -march=native, GCC 13.3), W = 4 on x86 without AVX2.
# Every run below gives results identical to the scalar recurrence (band_row_scalar), field by field.

== the row kernel alone (scratch microbenchmark: one band of width B over random rows; ns per cell, one thread)
galaxy  B = 500: scalar 2.83, vector 1.23 (2.3x);  B = 64: scalar 2.83, vector 1.28 (2.2x)
a2 AVX2 B = 500: scalar 3.12, vector 0.39 (8.1x);  B = 64: scalar 7.44, vector 0.69 (10.7x)
a2 SSE  B = 500: scalar 2.41, vector 1.29 (1.9x)
(an 8-lane build on aarch64 was 1.4x slower than scalar: two NEON registers per vector, and
cross-register shuffles; 4 lanes and an inclusive prefix maximum with in-register shuffles fixed it)
