# B5 — copy-level joint assignment (prototype): the recurring-mismatch signature, and its confound

**Date:** 2026-11-28. **Step:** Pillar B, B5 (copy-level joint assignment).
**Code:** [`../../b5_copy_em.py`](../../b5_copy_em.py). Output:
[`b5_out.txt`](b5_out.txt).

## Motivation

B2 showed the missing-copy class is a paralog **collapsed onto** a GRCh38 locus,
not a gap — so it needs copy-level reasoning. Reads from an unseen copy carry
mismatches vs the collapsed reference that recur at the same reference positions
across reads. This prototype detects those divergent positions and assigns reads
to the reference copy or a phantom copy.

## Method

For reads mapped into GRCh38 segdups (4 M-pair mapping): compute per-read mismatch
reference positions (CIGAR walk), group by segdup locus, mark positions mismatched
by ≥20% of the locus's reads (≥3) as divergent, assign a read to the phantom copy
if ≥2 of its mismatches are at divergent positions and ≥half of them. Validate
enrichment for the no-linear-truth class / misplacements.

## Result (galaxy)

- segdup reads: **554,575**; loci: 7,011; loci used (≥10 reads): 3,111.
- **phantom-assigned: 1,099 reads** — no-linear-truth **0 (0%)**, misplaced **0**,
  confident-misplaced 0.
- **reference-assigned: 536,118 reads** — no-linear-truth 609 (0.1%), misplaced
  3,893 (0.73%), confident-misplaced 728.

## Honest finding: the simple heuristic confounds het SNPs with missing copies

The phantom-assigned reads are all *correctly placed* (0 misplaced) — the
"divergent positions" picked out are **common heterozygous-SNP / error-hotspot
positions**, not missing-copy signatures. The actual missing-copy reads (609
no-linear-truth) stayed reference-assigned. A position mismatched by ≥20% of reads
at a segdup locus is usually a common variant, not paralog divergence.

So the recurring-mismatch *signature* is real but **not specific** at this
threshold: separating paralog divergence from het SNPs needs a proper copy-level
model — e.g. EM that estimates each copy's divergence profile jointly with read
assignment, uses the *pair* structure and the SD family's known copies, and models
the phantom copy's divergence δ separately from the population SNP rate. This is
the research frontier B5 names; the prototype establishes the pipeline and the
confound to overcome.
