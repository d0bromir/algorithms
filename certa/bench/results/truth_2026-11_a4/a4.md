# A4 — `--bio-phantom-bed`: a locus-specific copy-deficit prior (HG002 test B)

## Change

A3's phantom-copy term used a *global* prior π_∅, so it demoted divergent reads
everywhere (over-abstaining in unique sequence). A4 makes π_∅ **locus-specific**:
a `RegionTrack` of copy-deficit regions (here the GIAB GRCh38 segmental
duplications, 7,432 intervals merged to global coordinates) loaded from
`--bio-phantom-bed`. In `bio_place`, π_∅ = `phantom_pi` if the best hit's global
position is in a region, else `phantom_pi_unique` (default 0). So missing-copy
loci abstain while unique loci stay confident. `RegionTrack` tolerates a `chr`
prefix (UCSC BED vs Ensembl contigs). MAPQ only; certificate unchanged; no track
⇒ A3 global prior; phantom off ⇒ byte-identical.

## Results (4 M-read single-end subsample, test B mate 0; δ=0.01; locus π_∅=0.01 in segdups, 0 outside)

| run | MAPQ≥60 misplaced | MAPQ≥40 misplaced | MAPQ≥20 misplaced | MAPQ≥40 placed |
|---|---|---|---|---|
| `--bio` (baseline) | 358 | 461 | 819 | 3,147,250 |
| global phantom (A3, π_∅=1e-6) | 280 | 460 | 819 | 3,146,508 |
| **locus prior (A4)** | **144** | **190** | **609** | 3,069,030 |

- **MAPQ≥40 errors −59% (461 → 190)** and **MAPQ≥60 −60% (358 → 144)**, at a
  **~2.5% sensitivity cost** (78 k reads demoted below 40, 271 of them errors).
  The global prior barely touched MAPQ≥40 (460); the *locus specificity* is what
  realizes the gain.
- **Strata (MAPQ≥20 misplaced):** segdup 594 → **402 (−32%)**, lowmap_segdup
  690 → 497 (−28%), lowmap 643 → 467 (−27%), difficult 738 → 545 (−26%), tandem
  320 → 247 (−23%); **easy 7 → 7 (unchanged)**, mhc/par unchanged. The effect is
  concentrated in copy-deficit regions, as designed.
- **Missing-copy class** ("no linear truth", 10,899 mates): MAPQ≥20 221 → 182
  (−18%) — some truly-unplaceable reads are demoted too.
- **Calibration improves:** the MAPQ 50–60 band's overconfidence falls from
  393/3.2 ≈ 123× (bio) to 160/3.1 ≈ 52× (locus); the 20–29 band moves toward
  calibration (331/256).

## Interpretation

- A4 realizes much of the A1-validated headroom with a *principled* posterior
  term: ~2.4× fewer confident errors at MAPQ≥40 (A1's fitted gap map gave ~14×
  at matched N by abstaining more aggressively; A4 trades ~2.5% sensitivity for
  ~59% error reduction and keeps unique reads confident).
- The prior track is a **proxy** (GIAB segdups). More precise copy-deficit
  signals — Aganezov's 203 collapsed loci, CHM13 copy-excess via the chain —
  would sharpen it (fewer false abstentions in true-unique SDs, more in
  collapsed loci). π_∅=0.01 is a reasonable default; **A5 fits δ/π_∅** on HG002
  (freeze, HG005 holdout) to optimize the trade-off and recalibrate.

## Go / no-go

- **A4 validated** (keep; flag-gated, default byte-identical). Strong, selective
  confident-error reduction with the certificate intact.
- **Proceed to A5** (fit δ/π_∅/π_∅_unique on HG002, freeze, HG005 holdout;
  optionally a sharper copy-deficit track), then **extend the term to
  `bio_pair`/`bio_rescue`** for the paired production MAPQ.
