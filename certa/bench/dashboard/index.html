Against the slow, reliable mappers

Yara and RazerS 3 search exhaustively: each reports every alignment within an error rate, set here to cover CERTA's certificate radius (Settings, in the table below). They prove nothing about a read; CERTA proves each certified read optimal over the whole genome. CERTA runs in interval mode, so every read gets a record: at its default certification; with --full-cert --adaptive-parts 0 (the larger budget and local certificates); with --full-cert, which adds pass V, parts chosen per read: the rarest q-mers, then q-mers searched with one edit, certifying up to 12 edits; and with --full-cert --index2 (every pass again on a second index of 15-base parts). Winnowmap2 maps long reads only, so it is compared on HiFi reads. All on galaxy's 64 cores, index loading included.

Agreement with CERTA's certificates

On the reads CERTA certifies with --full-cert. End-to-end certificates prove the fewest edits (up to 12); "more edits" counts reads placed elsewhere with more edits than that, wrong under any scoring, while "worse locus" uses BWA-MEM's scores, under which equal edits can differ. "Unmapped" splits by the mapper's own error rate (4 % of the read length): within it they miss nothing; beyond it CERTA still proves the optimum. Local certificates prove the best clipped alignment, which these end-to-end mappers cannot report. RazerS 3 marks its first match primary, not its best, so both are shown.
